# IGrow PDF — downloads

IGrow's in-house PDF editor for Windows and Mac. This repository holds the installers and the update feed only.

**[Download the latest version →](https://github.com/IGrow-Wealth-Investments/igrow-pdf-releases/releases/latest)**

| Computer | File to download |
|---|---|
| Windows 10 / 11 | `IGrow-PDF-Setup-<version>.exe` |
| Mac with Apple Silicon (M1–M4) | `IGrow-PDF-<version>-arm64.dmg` |
| Mac with an Intel processor | `IGrow-PDF-<version>-x64.dmg` |

## First install

The installers aren't code-signed yet, so the computer warns you the first time:

- **Windows:** on the blue "Windows protected your PC" screen, click **More info → Run anyway**.
- **Mac:** drag IGrow PDF to Applications. The first time, **right-click the app → Open → Open**.

## Updates

- **Windows:** updates install themselves when the app opens. You'll see a short "Checking for updates…" window.
- **Mac:** the app tells you when a new version is ready to download.
